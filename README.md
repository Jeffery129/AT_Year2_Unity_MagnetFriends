## 🎮 どんなゲーム？

プレイヤーはそれぞれ **S極・N極** を切り替えられる磁石のキャラクター。
同じ極なら反発し、違う極なら引き合う。2人の極の組み合わせで、ジャンプの届かない場所へ飛ばし合ったり、重たい仕掛けを動かしたりしながらステージを進みます。

**1人では解けない。2人で「せーの」を合わせた瞬間が一番気持ちいい** ── そこを目指して作っています。

### 主なギミック

- **反発・吸着**：2人の極の組み合わせで、ジャンプの届かない足場に飛ばし合う
- **発電機**：2人が同時に極を切り替えてタンクのゲージを溜める
- **電気ドア**：帯電した状態でスイッチに触れると扉が開く
